# 云上视频播放

## 1. 目标与范围

本文对应两个 Android Demo 与一套 SpringBoot 接口：

1. 本地 Media Demo  
   - 播放固定目录中的本地视频  
   - 本地视频上传到云端（MinIO），支持断点续传

2. 云上 Media Demo  
   - 拉取云端视频列表（含封面 + 时长）  
   - 使用 HLS 播放云上碎片流  
   - 下载原始 MP4 到本地固定目录  
   - 将 HLS 缓存到本地（m3u8 + ts）  
   - 提供“FFmpeg 转 MP4”选项并下载

---

## 2. 方案选型：HLS vs DASH

### 2.1 主流平台常见做法

- 哔哩哔哩、YouTube、腾讯视频等通常使用 **自适应码率分片流**，核心思路是：
  - 服务端将源视频切分为多个片段；
  - 客户端根据网络与设备性能动态切换码率；
  - 通过 CDN 缓存分发，降低回源压力。
- 协议层面常见：
  - **HLS (m3u8 + ts/fmp4)**：生态成熟、兼容性好，移动端实现简单；
  - **MPEG-DASH (mpd + m4s)**：同样常见，尤其在部分浏览器/电视端。

### 2.2 本项目选择 HLS 的原因

1. Android 上使用 Media3/ExoPlayer，HLS 支持成熟。  
2. 你现有 Demo 已有 Media3 播放链路，改造成本低。  
3. 对“先快速打通端到端”的目标更友好。  

> 结论：本期优先 HLS，后续如需 DASH 可在后端增加并行转码产物与新播放地址。

## 3. 总体架构

1. **上传阶段（本地 -> 云）**  
   - Android WorkManager 分片上传（chunk）  
   - SpringBoot 接收 chunk 并落盘  
   - 上传完成后合并文件并写入 MinIO（OSS）

2. **云视频加工阶段（云 MP4 -> HLS + 封面）**  
   - SpringBoot 拉取原始视频  
   - FFmpeg 抽帧生成封面 jpg  
   - FFmpeg 转 HLS（index.m3u8 + ts）  
   - 将封面与 HLS 产物上传回 MinIO

3. **播放阶段（云 -> Android）**  
   - Android 请求播放地址  
   - SpringBoot 返回可播放 m3u8（并重写 segment 地址）  
   - Media3/ExoPlayer 播放 HLS

4. **下载与保存阶段**  
   - 列表页直接下载原始 MP4  
   - 播放页可下载 HLS 到本地  
   - 播放页可触发 FFmpeg 将 HLS 转 MP4，再下载保存

## 4. Android 端实现说明

### 4.1 固定目录策略

统一使用 `MediaDemoConfig` 管理路径：

- 本地视频目录：`local-video`（用于本地播放 + 上传源）
- 云下载目录：`cloud-download`（MP4 下载落地）
- HLS 缓存目录：`hls-cache`（m3u8 + ts 本地缓存）

这样可以确保“下载到哪里、播放从哪里读、上传从哪里扫”一致。

### 4.2 本地 Media Demo

页面：`LocalMediaDemoActivity`

- 启动后扫描固定目录中的视频文件（mp4/mov/mkv...）并列表展示；
- 每行两个按钮：
  - **播放本地**：跳到 `LocalVideoPlayerActivity`；
  - **上传云端**：触发 `ResumableUploadWorker`；
- 上传按钮支持：
  - 开始上传；
  - 暂停上传（取消 Worker）；
  - 继续上传（重新入队，服务端根据 session 恢复偏移）。

### 4.3 断点续传上传机制

Worker：`ResumableUploadWorker`

- 初始化：`/video/upload/init`
  - 服务端返回 `sessionId + uploadedBytes`；
- 分片上传：`/video/upload/chunk`
  - 按 offset 校验后追加写入；
- 完成提交：`/video/upload/complete`
  - 服务端将合并文件上传到 MinIO。

### 4.4 云上 Media Demo

页面：`CloudMediaDemoActivity`

- 拉取 `/video/cloud/list`；
- 列表展示：文件名、时长、大小、封面；
- 每行两个按钮：
  - **播放**：进入 `CloudVideoPlayerActivity` 播放 HLS；
  - **下载MP4**：直接下载原始 MP4。

### 4.5 云播放页

页面：`CloudVideoPlayerActivity`

- 首次进入直接播放后端返回 HLS 地址；
- 支持：
  - **保存 HLS 到本地**：把 m3u8 与 ts 下载到 `hls-cache`；
  - **播放本地缓存 HLS**：验证离线缓存播放；
  - **FFmpeg 转 MP4 并下载**：调用后端转换接口并下载结果。

## 5. SpringBoot 端实现说明

### 5.1 新增接口

上传相关：

- `POST /video/upload/init`
- `POST /video/upload/chunk`
- `POST /video/upload/complete`

云视频相关：

- `GET /video/cloud/list`
- `GET /video/cloud/thumbnail`
- `GET /video/cloud/hls/play.m3u8`
- `GET /video/cloud/hls/segment`
- `GET /video/cloud/download/mp4`
- `POST /video/cloud/hls/to-mp4`
- `GET /video/cloud/download/hls-mp4`

### 5.2 关键处理逻辑

1. **断点续传会话**
   - 以 `(userId, bucketName, fileName, fileSize)` 生成 sessionId；
   - 服务器保存会话元数据与 part 文件；
   - chunk 通过 offset 保障顺序与正确性。

2. **封面生成**
   - FFmpeg 抽第 1 秒附近关键帧为 jpg；
   - 上传到 MinIO，列表页用该 URL 展示。

3. **HLS 生成**
   - FFmpeg 将视频切分为 `index.m3u8 + seg_xxx.ts`；
   - 上传 HLS 产物到 MinIO；
   - 播放入口 m3u8 会重写片段地址到后端 segment 接口。

4. **HLS 转 MP4**
   - 后端执行 FFmpeg 将 HLS 合并为 MP4；
   - 再上传 MinIO；
   - Android 下载保存到本地目录。

## 6. FFmpeg 与部署注意事项

### 6.1 Docker 镜像

`demo/springboot/docker/Dockerfile` 已安装 `ffmpeg`，容器内可直接执行转码命令。

### 6.2 本地非 Docker 运行

如果你直接在本机启动 SpringBoot，需保证系统可执行 `ffmpeg` 与 `ffprobe`。  
可通过配置覆盖：

- `video.ffmpeg-bin`
- `video.ffprobe-bin`
- `video.work-dir`
