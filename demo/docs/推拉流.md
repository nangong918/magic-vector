**推拉流**
====


### 基本方案

推拉流方案：


采集：Android CameraX -> YUV -> 软编、硬编 (RK) 
推流：RTMP、RTSP (TCP、UDP) 
编码：播放H.264，传输H.265
组帧与透传：SpringBoot (Netty) 
播放：ExoPlayer、FFmpeg


### RTMP推流


数据流：
* Camera (CameraHelper.Camera) -> YUV数据
  1. -> TextureView (SurfaceHolder) 预览
  2. -> CameraHelper (Camera.onPreviewFrame) 
     * -> VideoStream.onPreviewFrame -> LivePusherNew.onVideoFrame -> native_pushVideo (JNI) 
        * -> VideoStream::encodeVideo (YUV -> I420 -> H264 NAL)
        * 组RTMP视频包sendSpsPps;sendFrame
  3. -> 推流线程取出 `RTMPPacket` 调用推流函数 `RTMP_SendPacket`
* Camera2 (ImageReader.OnImageAvailableListener)  -> ImageReader
  1. -> TextureView (SurfaceHolder) 预览
  2. -> reader  (YUV) -> 后续与上方Camera相同
* AudioRecord (AudioStream.AudioRecord) -> PCM数据
  1. -> onAudioFrame (回调数据) -> native_pushAudio (JNI) 
     -> AudioStream::encodeData (用 FAAC 编 AAC → 组 RTMP 音频包 → 入队)
  2. 推流线程发送，启动时先发一次 AAC AudioTag（DecoderSpecificInfo）
