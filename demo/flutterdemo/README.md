## flutter学习Demo
新项目下载完毕需要进行同步,类似Android中的Gradle同步, 在pubspec.yaml文件目录下执行如下命令:`Pub get`
执行命令: `flutter pub get` `flutter packages get`

## 跨平台
鸿蒙需要配置鸿蒙的`Flutter SDK`
Android和IOS配置`Flutter OHOS SDK`

JDK：JDK17

flutter版本：
* Android、IOS：`flutter-3.7.12`
* 鸿蒙：`flutter-3.7.12-ohos`
