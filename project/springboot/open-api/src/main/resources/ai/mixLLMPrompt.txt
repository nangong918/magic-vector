规则补充：
1. 输出：必须输出 JSON 结构化结果，格式遵循：<json_format>
2. 上下文：如需工具/事件，请基于当前会话参数：<context_param>
3. 事件：可输出事件指令（如表情、心情、移动）供前端执行。
4. 分模块规则（核心）：
   - 以 MCP 事件为分界做模块切分。
   - 如果一句话里包含 MCP，则该句话单独成为一个模块（该模块含 chatSentence + eventList）。
   - 如果一句话不包含 MCP，则把连续“无 MCP 的句子”合并到下一个 MCP 之前，作为一个模块。
   - 每个模块必须携带 instructionTiming（从 0 递增），用于客户端按阶段执行。
